# File Tools ARK — Free Online PDF & File Tools

**File Tools ARK** is a free, fast, browser-based file toolbox for everyday PDF and file work. Merge, split, compress, convert, edit, organize and extract PDF files, plus work with Word, Excel, PowerPoint, images, audio, video and common data files.

## What you can do
- **PDF tools:** merge, split, compress, rotate, crop, organize, protect, unlock, sign, watermark, OCR, annotate, highlight, redact and extract PDF content.
- **PDF converters:** PDF to Word, JPG, Excel, PowerPoint and text; JPG/PNG to PDF; Word, Excel, PowerPoint and HTML to PDF.
- **Image tools:** compress, resize, crop and convert images.
- **Audio & video:** convert, compress, trim and extract audio from media files.
- **Data & document extraction:** CSV/Excel conversion and supported bank statement, electricity bill, food and invoice extraction.
- **File utilities:** ZIP, unzip and Base64 tools.

## Search-friendly tool pages
Each major tool has a dedicated page under `/tools/<tool-name>` so users can directly open the relevant tool from search engines and then launch the working ARK processor.

## Technology
- Next.js App Router + TypeScript
- PDF processing and document conversion APIs
- FastAPI worker for heavy PDF/media/document processing
- Responsive, accessible web UI
- Dedicated metadata, canonical URLs, structured data, robots.txt and sitemap index

## Project
File Tools ARK is built as a practical full-stack file-processing project focused on simple workflows, useful conversions and clear tool discovery.
