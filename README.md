# PDF & File Tools ARK

A PDF-first, full-stack file toolbox built with Next.js and TypeScript.

## Architecture
- Next.js App Router frontend
- Node.js route handlers for server-side document processing
- pdf-lib for PDF operations
- Browser APIs for privacy-friendly image operations
- Vercel deployment target

The toolbox is intentionally organized PDF-first, then image, audio/video, and other file conversions.
